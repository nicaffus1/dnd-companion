# D&D Companion
Version 0.2.0 — local data foundation. Mobile-first personal D&D companion. Five tabs, forest green and gold, offline PWA shell. Create and switch campaigns with 2014 or 2024 rules; create basic character records; rename records. Settings includes JSON backup and reviewed replacement restore. Gameplay modules are planned. Run npm install, npm test, npm run dev. GitHub Pages workflow generates PNG icons, tests and builds. Set Settings > Pages > Source to GitHub Actions. On iPhone use Safari > Share > Add to Home Screen after successful deployment. Data is local to the browser/app origin and may be erased; regularly download backups. No personal data is transmitted.
