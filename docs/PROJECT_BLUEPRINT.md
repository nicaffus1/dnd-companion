# Approved blueprint
Personal mobile-first D&D Beyond-inspired PWA hosted on GitHub Pages; dark forest green and gold; name deferred. Multiple characters and campaigns; selectable 2014 and 2024 rules; local storage with downloadable backups; offline support. Guided character creation and level-up with prerequisites and overrides; full character sheet, combat, rests, conditions, companions. Animated 3D dice, presets, custom formulas, checks, saves, attacks, damage and history. Copy individual/grouped rolls and character/campaign context. Permitted official catalog plus custom/imported content; equipment, containers, weight, currency, attunement, charges and consumables. Class/level filtered spells, preparation, concentration, slots and resources. Journal chapters and sessions; Codex characters, locations, factions, lore, creatures, quests and relationships. Structured ChatGPT updates with review before applying. Build architecture first, then test each module.
