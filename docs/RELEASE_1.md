# Version 1.0.0 release candidate
Local-first application with five gameplay tabs and reviewed ChatGPT exchange. New: companions/familiars/summons/mounts with HP, AC, initiative, notes and imported monster reference; natural 1/20 death-save handling and counters; optional ammunition consumption atomic with attack history; Wand of Magic Missiles dawn recovery (1d6+1, capped); shared level-up dice history; manual spell preparation markers; advisory 2014 variant encumbrance; preservation of existing spent hit dice; frightened and invisible roll effects; focus styling and reduced-motion CSS; removal of planned-feature panels; cached navigation fallback on HTTP errors. Schema 10 adds characterExtras. Previous backups migrate; download a backup before upgrading. Known limits: no exhaustive feat effects, special multiclass grants, strict class spell eligibility/preparation limits, concentration loss on damage, automatic critical damage or failures at zero HP, full condition effects, all magic-item effects, other random recharge formulas, container volume, companion attacks, graphical world maps or direct ChatGPT API. Ammunition must be selected and exact item names recognized; no selected ammunition means manual tracking. Encumbrance is advisory. Dawn recharge requires manual confirmation of timing. Large-library performance and device accessibility are not benchmarked. Release branch CI must pass before deployment on main.
