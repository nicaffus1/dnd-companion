# Interactive character sheet
Schema 5 adds per-character sheet state and persistent scoped copy queue. Health uses fixed single-class hit dice and current CON, with explicit maximum override. AC is an estimate from selected gear, not equipped inventory. Built-in weapon rolls assume proficiency; custom attacks allow ability, proficiency and extra bonuses. Single-class spell slots and Pact Magic tracked, imported tables used when recognized; multiclass and complex spell effects deferred. Imported features displayed by level, manual charges support short/long/manual reset. Rest prerequisites and situational effects require user review. Conditions are tracked; only selected basic effects automated. Death saves manually adjudicated. No automatic inventory transfer. All sheet rolls use existing validated dice history and shared queue. Older backups migrate without resetting records.
