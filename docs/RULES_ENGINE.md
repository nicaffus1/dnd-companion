# Core rules engine v0.3.0
Pure functions in src/rules/shared/core.mjs; edition strategies in 2014 and 2024; public entry point index.mjs. No database changes. Score 1–30, level 1–20, explicit additive modifiers and final overrides. Skills accept alternate ability and half/proficient/expertise multipliers; AC accepts one selected base formula and explicit bonuses. HP uses ordered level history, fixed or rolled gains, current Constitution and minimum one per level; health helpers do not manage death saves, healing eligibility or damage resistances. Weapon ability, proficiency, special damage and modifiers supplied by caller. Spell DC and attack support explicit bonuses. Combined spell slots only for multiple classes that actually have Spellcasting, with caller-supplied progression; single-class tables, Pact Magic and special classes deferred. Exhaustion and rest functions return mechanical effects, not automatic state changes. Preview is temporary, not saved. Full condition automation, class features, spell preparation, feat prerequisites, death saves, equipment catalog and level-up UI follow in later phases.
