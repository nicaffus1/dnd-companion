# Architecture
React + TypeScript + Vite, Lucide icons and CSS tokens. Feature modules separate from rules and persistence. Phase 2 uses native IndexedDB with a validated snapshot and revision-checked transactions; pure data model and typed interface, fake-indexeddb test coverage. Dexie/Zod were proposed but not necessary for this small initial schema; evaluate for later migrations and larger catalogs. Planned Three.js and candidate Rapier. Static GitHub Pages, hash navigation, scoped service worker and versioned precache. No server or API key required. Personal data stays on device.
