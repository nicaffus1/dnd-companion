# Journal and world codex
Schema 8 adds worldRecords and worldLinks, validated by campaign, stable IDs, type and reference integrity. Journal kinds: chapter, session, event. Codex: npc, location, faction, creature, quest, lore. Shared title, summary, notes, tags, status, free-form date, optional chapter/session and creature catalog reference. Links are directional, editable and cross-module. Deleting a record removes its links and clears references, retaining child records. ISO dates order chronologically; fictional dates are stored verbatim and use creation order. Imported creature data stays local and is read-only in the reference; notes remain editable. Export is read-only campaign-scoped JSON for Phase 11, not an import protocol. No external transmission. Full backups include world records.
