# Content foundation
Partial, manually structured reference index based on SRD 5.1 and 5.2.1; not a complete catalog or mechanically verified rulebook. Names, selected base stats and reference metadata only. Edition-specific IDs. Custom and imported content is local, descriptive only; imports require review, reject duplicates, and cannot replace built-in IDs. Profiles provide level, six scores, skill multipliers and save proficiency; linkedChecks calculates 30 check/save/skill modifiers. No profile editor or dice UI integration until Phase 6/7.
