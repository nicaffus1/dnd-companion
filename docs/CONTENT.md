# Content foundation
Partial, manually structured reference index based on SRD 5.1 and 5.2.1; not a complete catalog or mechanically verified rulebook. Names, selected base stats and reference metadata only. Edition-specific IDs. Custom and imported content is local, descriptive only; imports require review, reject duplicates, and cannot replace built-in IDs. Profiles provide level, six scores, skill multipliers and save proficiency; linkedChecks calculates 30 check/save/skill modifiers. No profile editor or dice UI integration until Phase 6/7. ## v0.5.1 import capacity
25 MB UTF-8 per pack; 10,000 entries per pack; 30,000 custom entries and 75 MB combined compact custom JSON; 40,000 characters per description. Full backup limit 150 MB; compact JSON exports. Review displays first 100 entries and total count; all entries validated. Duplicate IDs still rejected. Actual mobile capacity depends on memory and browser storage quota. No schema change.\n
